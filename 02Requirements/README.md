PB-01: Capture detailed device information upon entry (type, brand, model, serial number, and reported faults) using a simple form to uniquely identify each job.

PB-02: Change the service status using a static dropdown menu (Options: Under Diagnosis, Under Repair, Ready) so technicians can manually update the progress.

PB-03: Display a simple list of previous jobs, filtered by customer name or serial number.

PB-04: Allow the user to manually enter the labor cost and parts cost so the system displays the total on screen.

PB-05: Manually register the available quantity of spare parts and display a text message if the number is less than 3 units.

PB-06: Select an estimated delivery date from a visual calendar when registering the equipment.

PB-07: Mark with a checkbox (checklist) whether the equipment has a valid warranty or not during registration.

PB-08: Allow the customer to check the status of their equipment by entering their order number on a simple search screen.

PB-09: Generate a plain text report or a simple list showing the total money collected and the number of repairs performed in the month.
